# Stackware Ltd 

**Custom software development company specialising in HMI modernisation, embedded interfaces, and connected products.**

We transform outdated HMIs into modern, premium interfaces, and build custom desktop, mobile, embedded, web and cloud applications. We work across manufacturing, medical, automotive, retail and enterprise, taking products from concept to production with one integrated team accountable throughout.

---

## What We Do 🛠️

- **HMI Modernisation** – Redesigning dated, clunky industrial and product interfaces into fast, intuitive, premium experiences, integrated with existing systems, without a full rebuild.
- **Embedded & Connected Products** – Bridging hardware and software: device interfaces, control systems, IoT connectivity and telemetry.
- **Desktop, Mobile & Web Applications** – Cross-platform software built to fit the product, from operator panels to companion apps to full web platforms.
- **AI-Powered Interfaces** – Voice control, natural-language interaction and intelligent features, added where they earn their place.
- **UI/UX Design** – Considered interface and interaction design for demanding real-world environments, from factory floors to clinical settings.

## Selected Work 📦

**ParcelPort – Smart Parcel Locker System**
A complete, working smart parcel locker platform built end to end: physical locker hardware, a touchscreen kiosk interface, and a mobile app with live tracking. Booking, drop-off, secure storage, collection and real-time updates, all connected.

**3D Printer Control Interface**
A rich, interactive 3D user interface for a 3D printing application, built in Qt: real-time 3D model visualisation on a virtual print bed, camera control, model manipulation, grouping, and a navigation cube. Available as a live Qt WebAssembly demo.

**Medical Monitoring System**
Interface and software for a clinical monitoring system tracking patient vital parameters in real time, built for the clarity and reliability a medical environment demands.

**Automotive Infotainment System**
An in-vehicle infotainment experience integrating media, navigation and vehicle controls into one coherent, responsive interface.

**Online Assessment Platform**
A secure, multi-tenant web platform for structured online assessments at scale, with credit-based billing, multi-language support and branded certificate generation.
